        Quick Start Guide

📋 LANGKAH-LANGKAH SETUP:

1. INSTALL NODE.JS (jika belum punya)
   ✓ Download dari: https://nodejs.org/
   ✓ Pilih versi LTS (Long Term Support)
   ✓ Install seperti biasa

2. BUKA TERMINAL / COMMAND PROMPT
   ✓ Windows: tekan Win + R, ketik "cmd", Enter
   ✓ Mac: tekan Cmd + Space, ketik "terminal", Enter

3. MASUK KE FOLDER PROJECT
   cd portfolio-react

4. INSTALL DEPENDENCIES
   npm install
   
   (tunggu proses selesai, biasanya 2-5 menit)

5. COPY GAMBAR
   ✓ Copy semua file gambar dari portfolio lama
   ✓ Paste ke folder: portfolio-react/public/img/
   
   Gambar yang dibutuhkan:
   - background.jpg
   - logo-wayang.png
   - logo1.jpg
   - logo2.jpg
   - favicon.ico
   - show.jpg, show2.jpg, show3.jpg, show4.jpg, show5.jpeg
   - project0.png hingga project6.png

6. JALANKAN PROJECT
   npm start
   
   Website akan otomatis terbuka di browser!
   URL: http://localhost:3000

═══════════════════════════════════════════════════════════════

❗ TROUBLESHOOTING:

Problem: npm tidak dikenali
→ Install Node.js terlebih dahulu

Problem: Port 3000 sudah digunakan
→ Akan otomatis ditanya apakah mau pakai port lain, ketik "Y"

Problem: Gambar tidak muncul
→ Pastikan semua gambar sudah di-copy ke public/img/

Problem: Error saat npm install
→ Hapus folder node_modules dan package-lock.json
→ Jalankan npm install lagi
